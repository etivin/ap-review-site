# Released AP World History: Modern FRQs

Catalog of every released free-response question (2018–2026), built from Mr. Tivin's copy of the **APWH Released Exam FRQs** spreadsheet (Google Drive, Oct 2026). Use it to find a prompt by unit, open the official PDF, or check the scoring guidelines.

- **PDFs in this folder:** the 11 prompt booklets (`YYYY-setN-prompts.pdf`). They contain every SAQ passage/image and every DBQ document set. College Board encrypts these files; they open normally in a browser or Acrobat.
- **Scoring guidelines, Chief Reader reports, statistics, and sample responses** are linked below (shared Google Drive copies).
- **Used on site** = the prompt already appears on that unit's Writing page (`writing-prompts.js`). Unit 7's own writing page also uses the 2024 Set 2 DBQ.
- 2018 and 2019 are the old course format (some prompts are pre-1200). The unit tags come from the spreadsheet; "0" means pre-1200 content.
